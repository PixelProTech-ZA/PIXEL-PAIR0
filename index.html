PIXEL PAIR

YOUR PHONE. YOUR PC. ONE CONTROL SURFACE.

Turn your phone into a wireless trackpad and keyboard for a Windows PC. Local network only. No account, no cloud, no screen sharing.

PIXEL PAIR runs on your own computer, not in this web page. Download it, start it, and pair your phone with a QR code.

DOWNLOAD FOR WINDOWS (ZIP)

SET UP IN 4 STEPS

  1. Install Node.js LTS on the PCOne time only, from nodejs.org.
  2. Unzip and run start-pixel-pair.batKeep the window open. If Windows Firewall asks, allow Private networks.
  3. Press PAIR DEVICE on the PCA QR code appears. It expires in 2 minutes.
  4. Scan it with your phone cameraSame Wi-Fi as the PC. Tap PAIR and the trackpad opens.
Know before you use it. The phone link is plain HTTP on your local network, so use trusted Wi-Fi only. System commands and shutdown are OFF by default and can only be switched on from the PC.
