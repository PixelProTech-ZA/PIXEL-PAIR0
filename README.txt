PIXEL PAIR v1 — PixelProTech Solutions — PAIR. TOUCH. CONTROL.
1. Install Node.js LTS on the Windows PC (once).
2. Double-click start-pixel-pair.bat. Allow Windows Firewall on PRIVATE networks when asked.
3. The PC window opens. Press PAIR DEVICE. Scan the QR with the phone camera (same Wi-Fi).
4. Phone: PC FOUND -> PAIR. Control starts at TOUCH.
Permissions (System commands, Shutdown/restart) are OFF by default and can only be changed on the PC.
Paired devices are stored in %APPDATA%\PixelPair-devices.json (token hashes only).
Traffic is plain HTTP/WS on the local network: use trusted Wi-Fi only.
